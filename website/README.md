# GoreeCloud Website Artwork

This directory is the canonical source for GoreeCloud-controlled artwork used specifically by first-party GoreeCloud website experiences when the artwork is not itself a product, service, platform-system, or parent-platform identity.

Website artwork must follow Glaze UI and GoreeCloud visual-asset requirements, remain source-traceable, and avoid letter/initial placeholders, emoji substitutes, arbitrary gradients presented as identity, random imagery, and blank visual containers.

Artwork here does not create implementation, release, privacy, security, lifecycle, or production-readiness authority. Product, service, and platform-system identities belong in their corresponding canonical namespaces.

On review branches, newly introduced artwork remains a review candidate until the governing visual review and merge are complete.
